## 双视角重构：用户视图 / 创作者视图
- 需求：同一套组件骨架、按视图状态切换交互与可编辑性；切换控件只对运营白名单可见，普通用户看不到。
- 新增 `MidsummerViewMode.swift`（viewer/creator + `MidsummerViewModeStore`，显式 `ObservableObjectPublisher`——`@MainActor`+`@Published` 合成 conformance 会挂）；`MidsummerStore.canEnterCreatorView`（allowed→可见 / denied→不可见 / unresolved→本机创作者模式放行）。
- 顶栏：右上角两段胶囊分段控件（当前视角橙色高亮+图标），创作者视图下其正下方挂「上传上新」；用户视图无上传。
- 首页卡片：创作者视图加「点击编辑名称 / 图片 / 描述」角标 + 更紧凑留白；点击直接进编辑态。
- 详情页 `MidsummerItemDetailSheet`：同一骨架，`startsEditing`/编辑按钮切换——编辑态为名称输入框 + 描述 TextEditor + 换主图 PhotosPicker + 保存（走 `MidsummerCloudService.publish` 整条重写链路，保存后 `refreshFromCloud()` 回读）；用户视图只读。
- 坑 1：SwiftUI 容器 `.accessibilityIdentifier` 会合并给子元素——两段切换按钮报同一个 identifier，UI 测试改用 label（「用户视图」/「创作者视图」）查询。
- 坑 2：`CreatorMode.shared` 原本只在设置页创建，UI 测试启动参数（reset/enable）要等设置页打开才生效 → 在 `ItemManagerApp.init` 提前 `_ = CreatorMode.shared`，否则门控读到上次运行残留值，用例互相污染。
- 测试：testE 改为「白名单可见切换 → 切创作者 → 上传直达新建系列」；新增 testF「普通用户看不到切换与上传」；单测+快照 25 例复跑全绿。
