## Ponytail MCP 安装

- 用户要求安装 [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) 插件
- Ponytail 是一个 AI 编程规则集，核心理念是"懒惰高级开发者"：写代码前先爬懒惰阶梯（YAGNI → 复用 → 标准库 → 平台原生 → 已有依赖 → 一行代码 → 最小可行代码）
- 安装方式: 通过 MCP server (`ponytail-mcp`) 接入 WorkBuddy
  - 仓库克隆到 `~/.workbuddy/mcp-servers/ponytail`
  - 在 `~/.workbuddy/mcp.json` 注册 `ponytail` MCP server
  - 已通过 smoke test 验证 server 正常响应
  - 提示用户需要在连接器管理页 Trust 该 server
