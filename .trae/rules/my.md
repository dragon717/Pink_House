# 项目特定规则

## SwiftUI 开发规范

### 1. 折叠面板模式

当实现可展开/折叠的UI组件时：

- 使用 `@State private var expanded: Bool` 控制状态
- 切换时使用 `withAnimation` 添加动画
- 折叠状态应显示有意义的摘要信息，而非完全空白
- 摘要数据通过计算属性计算，保持 body 简洁

### 2. 最近数据计算模式

计算"最近"的数据（如最近月份、最近任务等）：

```swift
// 优先找当前时间之后的数据，如果没有则取最后一个
let nearest = items.first(where: { $0.date >= now }) ?? items.last
```

### 3. 空状态处理

统计数据组件必须处理无数据情况：

- 使用 `hasData: Bool` 标志
- 空状态时显示友好的提示文本（如"暂无数据"）

### 4. 组件复用

相同功能的UI组件应抽象为可复用组件：

- 使用元组传递数据，保持组件通用性
- 命名元组提高可读性：`(month: Int, count: Int, hasData: Bool)`

## 代码组织原则

### 文件拆分时机

当文件超过500行时，考虑按以下维度拆分：

- 按功能模块（如选择器、卡片、统计等）
- 按视图和逻辑（View + ViewModel）
- 按复用程度（提取通用组件）
