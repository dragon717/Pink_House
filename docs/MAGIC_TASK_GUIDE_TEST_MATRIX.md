## 三、重点验收标准（流程“合理”定义）

1. **触发合理**：点击“新手引导”后，必须能进入对应引导，不出现“无响应”。  
2. **路径合理**：跨页面引导先完成导航，再显示引导，不抢跑。  
3. **状态合理**：manual 体验类任务在完成引导后可完成（不再长期卡未完成）。  
4. **交互合理**：跳过/完成/展开说明均不影响主流程，且可重复进入。  
5. **视觉合理**：高亮框与目标控件对齐，特别是 AI 引导中的 VIP 卡片/兑换按钮、Wealth 引导中的「马上来财」入口/页签控件。
