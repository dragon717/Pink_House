## 三、重点验收标准（流程“合理”定义）

1. **触发合理**：点击“新手引导”后，必须能进入对应引导，不出现“无响应”。  
2. **路径合理**：跨页面引导先完成导航，再显示引导，不抢跑。  
3. **状态合理**：manual 体验类任务在完成引导后可完成（不再长期卡未完成）。  
4. **交互合理**：跳过/完成/展开说明均不影响主流程，且可重复进入。  
5. **视觉合理**：高亮框与目标控件对齐，特别是 AI 引导中的 VIP 卡片/兑换按钮、Wealth 引导中的「马上来财」入口/页签控件。  
6. **返回合理**：凡是文案写“返回到某页”的步骤，用户看到的真实页面必须同步变化。  
7. **滑动合理**：凡是文案写“下滑找到某入口”的步骤，必须给清楚方向提示，且说明气泡不能遮住目标。  
8. **复用合理**：解锁前复用引导可以共用路径，但文案和完成条件必须体现当前功能差异。  
9. **House 合理**：热区入口、底部导航 / House 房间入口、编辑器入口应分别通过真实 page-open / action 事件推进。
10. **创建合理**：涉及“创建手帐 / 创建书页 / 进入编辑器 / 打开扫描”的多段链路，不能靠定时器连跳。  
11. **主题一致**：所有“文字提醒框”（标题/正文/跳过胶囊/进度点/主按钮）在魔法配色、客制化配色、个性化配色下均使用同一套语义色，不出现硬编码紫/粉/灰导致的割裂。  
12. **奖励合理**：体验任务鱼币必须按引导步数分档，且仅在首次完成该 manual 任务时发放一次。  
13. **容器避让合理**：iOS18 Legacy 底栏场景下，设置页容器必须统一预留底部可滚动空间，避免末尾内容被遮挡。  
14. **命中模型合理**：有引导时，高亮步骤若要求点击高亮框，必须存在引导层自己的透明交互区；无引导时，House 热区不得被全局悬浮手势层拦截。
