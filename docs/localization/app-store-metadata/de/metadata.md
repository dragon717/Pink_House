## Description

Pink House ist dein digitaler Kleiderschrank und virtueller Haustier-Begleiter.

Organisiere Kleidung, verfolge Anzahlungen, führe ein Outfit-Tagebuch und pflege süße Haustiere. Themes, VIP-Vorteile und KI-Styling inklusive.

**Virtuelle Währung:** Meow Coins per In-App-Kauf für Themes, Haustier-Items und VIP-Zeit. VIP wird **manuell** mit Meow Coins eingelöst — **kein** Auto-Abo.
