## Description

Pink Houseは、デジタルクローゼットとバーチャルペットの相棒アプリです。

服を整理し、支払いやコーデを記録。コーデ日記をつけ、かわいいペットを育てましょう。テーマスキンで装飾し、VIP特典やAIコーデ提案も楽しめます。

**仮想通貨：** アプリ内課金で「ニャンコイン」を購入し、テーマ・ペットアイテム・VIP期間の解除に使用します。VIPはニャンコインを**手動で交換**する方式で、**自動更新サブスクリプションではありません**。

仮想アイテムの返金・現金化はできません。
