## Promotional Text

新しい服の写真にサイズや前払い金を記録。残金の支払日を確かめたり、コーデ手帳で前回の着こなしを振り返ったりできます。

## Description

服の写真にサイズやタグ、購入情報を添えて、自分だけのクローゼットを作りましょう。予約した服は前払い金と残金を分けて記録できます。着た日のコーデを手帳に残せば、後から見返せます。

時のギャラリーでは、ドレスを見て、気に入ったものをクローゼットに追加できます。アプリ内で購入したニャンコインは、アイテムや期間制のVIP特典と交換できます。VIPの利用期間が終了すると、特典も終了します。
