## Description

Pink House는 디지털 옷장과 버추얼 펫 동반 앱입니다.

옷장을 정리하고, 코디와 잔금을 기록하며, 코디 다이어리를 작성하고 귀여운 펫을 키우세요. 테마 스킨, VIP 혜택, AI 코디 제안을 즐길 수 있습니다.

**가상 화폐:** 인앱 구매로 「냥코인」을 구매해 테마, 펫 아이템, VIP 기간을 해제합니다. VIP는 냥코인을 **수동 교환**하는 방식이며 **자동 갱신 구독이 아닙니다**.

가상 아이템은 환불·현금화 불가.
