## 四条轨道（执行前必读）

1. **App 可用性** — ASC Pricing and Availability  
2. **Metadata 本地化** — 商品页 Name / Description / 截图  
3. **Binary 本地化** — `Localizable.xcstrings`、InfoPlist、Widget  
4. **合规/支付** — Agreements、Tax、Privacy、Age、地区许可  

四条均满足后才应一次性开「所有地区」。
