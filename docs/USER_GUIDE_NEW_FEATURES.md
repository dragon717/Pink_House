# 少女心愿衣橱 (Pink House) - 新功能使用指南

本文档旨在介绍应用程序新增的三项核心功能：CSV 导出、数据备份与恢复、以及 iCloud 数据同步。

## 1. CSV 导出功能

### 功能描述
允许用户将应用内的所有衣物数据导出为通用的 CSV（逗号分隔值）格式文件。该文件可被 Excel、Numbers 表格等软件打开，方便用户进行自定义统计和记录。

### 使用步骤
1.  打开应用，进入底部的 **"我的" (Me)** 页面。
2.  点击右上角的 **"设置"** 或 **"数据管理"** 选项（具体入口视当前 UI 布局而定，通常在设置菜单中）。
3.  找到 **"备份与导出"** 区域。
4.  点击 **"导出 CSV (Export CSV)"** 按钮。
5.  系统将生成一个包含当前所有衣物数据的 `.csv` 文件。
6.  在弹出的系统分享面板中，选择保存位置（如 "文件" App）或直接发送给微信/邮件等。

### 导出字段说明
导出的 CSV 文件包含以下列：
*   **名称**: 衣物名称
*   **品牌**: 所属品牌
*   **标签**: 关联的标签
*   **类型**: JSK, OP, SK 等
*   **颜色**: 颜色信息
*   **尺码**: 尺码信息
*   **衣长**: 长度信息
*   **状态**: 全新/二手等
*   **小物**: 包含的小物列表
*   **价格**: 总价
*   **定金**: 已付定金
*   **尾款**: 剩余尾款
*   **购买日期**: 购买/记录时间
*   **备注**: 备注信息
*   **库存**: 数量
*   **上架状态**: 上架/下架

## 2. 数据备份与恢复功能

### 功能描述
提供完整的数据备份机制，确保用户数据安全。支持生成包含所有品牌、标签、衣物信息的 JSON 备份文件，并能在需要时恢复。

### 如何备份数据
1.  进入 **"数据管理"** 页面。
2.  点击 **"备份数据 (Backup Data)"** 按钮。
3.  系统将生成一个 `.json` 格式的备份文件。
4.  选择保存位置（建议保存到 iCloud Drive 或其他安全位置）。

### 如何恢复数据
1.  进入 **"数据管理"** 页面。
2.  点击红色文字的 **"恢复数据 (Restore Data)"** 按钮。
3.  在文件选择器中，找到并选择之前导出的备份文件 (`.json`)。
4.  **警告**：系统将弹出确认对话框。**恢复操作会完全覆盖当前应用内的所有数据**，且不可撤销。
5.  确认无误后，点击 "确认恢复"。恢复完成后，界面会自动刷新显示新数据。

## 3. iCloud 数据同步功能

### 功能描述
利用 Apple iCloud 云服务，在您的多个 Apple 设备（如 iPhone、iPad）之间自动同步衣橱数据。

### 如何开启/关闭
1.  进入 **"数据管理"** 页面。
2.  找到 **"同步设置"** 区域。
3.  切换 **"iCloud 同步"** 开关。
    *   **开启**：将数据迁移至云端数据库，实现多端同步。
    *   **关闭**：仅在当前设备本地存储数据。
4.  **注意**：更改此设置后，系统会提示您**手动重启应用程序**以使更改生效。请从后台彻底关闭应用后重新打开。

### 重要说明
*   **同步范围**：目前仅支持同步**文本数据**（如衣物信息、价格、品牌、标签等）。
*   **图片限制**：由于图片文件体积较大，目前**图片仅保存在本地设备**，不会通过 iCloud 自动同步到其他设备。在其他设备查看同步过来的数据时，如果本地没有对应的图片文件，可能无法显示图片。
*   **账号要求**：所有设备需登录同一个 Apple ID，并开启 iCloud Drive 和应用的 iCloud 权限。
