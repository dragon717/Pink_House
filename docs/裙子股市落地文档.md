## 一、项目概述

### 1.1 项目背景

裙装股市是一个基于 **SwiftData + CloudKit Public DB + AI** 的分布式 Lolita 裙装价格监控系统。它将金融股市的概念与 Lolita 文化相结合，利用多台 iPhone 作为分布式计算节点，实时追踪闲鱼、小红书、淘宝、微店等平台的裙装价格变动。

### 1.2 核心功能

- **大盘指数 (LO-Index)**：综合反映市场热度
- **萌款股市**：单个裙装的 K 线图和价格走势
- **分布式监控**：多台 iPhone 协同采集数据
- **AI 去重**：MiniMax + Qwen-3-VL 双 AI 引擎去重
- **价格预警**：白菜价自动推送通知

#### 关键设计决策

| 决策 | 说明 | 原因 |
|------|------|------|

| **内存过滤** | 谓词查询后内存中过滤枚举 | `#Predicate` 不支持枚举比较 |

## 三、关键问题与解决方案

### 3.1 CloudKit 集成问题

#### 问题 1：unique 约束不支持
```
CloudKit integration does not support unique constraints.
```

**解决方案**：
- 移除所有 `@Attribute(.unique)`
- 在应用层通过 `SkirtIndexCache` 实现去重

```swift
// ❌ 错误
@Attribute(.unique) var platformID: String

// ✅ 正确
var platformID: String = ""
```

#### 问题 2：枚举类型 rawValue
```
Failed to validate \MonitorTask.status.rawValue because rawValue is not a member of TaskStatus
```

**解决方案**：
- 枚举 rawValue 使用英文字符串
- 添加 `displayName` 属性用于显示

```swift
// ❌ 错误
enum TaskStatus: String {
    case pending = "待处理"
}

// ✅ 正确
enum TaskStatus: String {
    case pending = "pending"
    
    var displayName: String {
        switch self {
        case .pending: return "待处理"
        }
    }
}
```

#### 问题 3：#Predicate 不支持枚举比较
```
Key path cannot refer to enum case 'pending'
```

**解决方案**：
- 先获取所有数据
- 在内存中过滤

```swift
// ❌ 错误
static func predicateForPending() -> Predicate<MonitorTask> {
    #Predicate { task in
        task.status == TaskStatus.pending
    }
}

// ✅ 正确
static func filterPending(from tasks: [MonitorTask]) -> [MonitorTask] {
    tasks.filter { $0.status == .pending }
}
```

```swift
enum TaskStatus: String, Codable, CaseIterable {
    case pending = "pending"

        case .processing: return "处理中"
        case .completed: return "已完成"
        case .failed: return "失败"
        case .expired: return "已过期"
        }
    }
}
```
