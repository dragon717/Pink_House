# 设置页面重构方案 v2 (基于业务模块)

根据您的反馈，我们将设置项按照**业务模块**进行重新聚合，并采用**豆腐块 (Grid)** 的视觉风格。

## 1. 核心分类 (四大板块)

我们将设置主页重构为 `2列 x 2行` 的网格布局（豆腐块），包含以下四个卡片：

### 👗 梦幻衣橱 (Wardrobe)
*聚合所有与裙子管理、展示相关的设置。*
*   **外观个性化**: 卡片样式（液态/磨砂）、背景图片、填充模式。
*   **隐私显示**: 列表价格显示开关（入库价/原价）。
*   **业务提醒**: 尾款天使通知设置。
*   **基础数据**: 属性字段管理、标签/品牌管理、回收站。

### 🌍 小世界 (Small World)
*聚合小世界场景的所有配置。*
*   **风格切换**: 法式复古 / 洛可可 / 更多风格。
*   **环境设置**: 场景时间模式（晨曦/夕阳/自动）、光照调整。
*   **高级特性**: 3D 空间场景开关 (iOS 26+)。

### 🐾 智能萌宠 (AI & Pet)
*聚合 AI 大脑与萌宠交互的所有设置。*
*   **AI 大脑**: 视觉/文字模型优先级、API Key 配置。
*   **萌宠形象**: 气泡样式、足迹特效。
*   **声音交互**: 语音音色选择、语音音量。

### 📱 系统与更多 (System & More)
*聚合全局系统功能、数据备份与通用设置。*
*   **数据安全**: iCloud 同步、整机备份与恢复、CSV 导出。
*   **桌面组件**: 小组件背景与样式设置。
*   **通用设置**: 语言切换、全局触感/音效开关、系统权限检查。
*   **存储优化**: 清理缓存图片、内存优化。

---

## 2. UI 设计风格 (豆腐块)

*   **布局**: 使用双列网格 (`LazyVGrid`)。
*   **卡片样式**:
    *   每个卡片为一个圆角矩形（豆腐块）。
    *   **视觉元素**: 左上角/中心显示具有代表性的大图标（Emoji 或 SF Symbol，如 👗, 🌍, 🐾, ⚙️）。
    *   **标题**: 清晰的模块名称。
    *   **描述**: 一行小字，列出该模块下的核心功能（例如：“外观 · 隐私 · 提醒”）。
    *   **背景**: 使用轻微的磨砂或半透明背景，保持 App 统一的梦幻风格。

## 3. 页面层级变化

*   **当前**: MeView -> [长列表]
*   **重构后**: MeView -> [用户信息] + [VIP卡片] + [2x2 设置网格]
    *   点击 **[👗 梦幻衣橱]** -> 进入新页面 `WardrobeSettingsView` (包含原本分散的裙子相关设置)
    *   点击 **[🌍 小世界]** -> 进入新页面 `SmallWorldSettingsView`
    *   点击 **[🐾 智能萌宠]** -> 进入新页面 `PetAISettingsView`
    *   点击 **[📱 系统与更多]** -> 进入新页面 `SystemSettingsView`

此方案能极大减少“我的”页面的垂直长度，让核心功能一目了然。
