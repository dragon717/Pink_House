## 二、`ItemManager/` — iOS 主工程

### 2.1 一级目录

| 目录 | 职责 | 放 | 不放 |
| :-- | :-- | :-- | :-- |
| `Views/` | 页面、模块视图、私有组件 | `xxxView.swift`、模块子目录 | 跨模块通用组件 |
| `ViewModels/` | 跨页面共享的视图状态 | `@Observable` 视图模型 | 一次性 `@State` |
| `Services/` | 业务与系统能力封装 | `*Service` / `*Manager` | UI |
| `Models/` | SwiftData `@Model`、配置枚举 | 数据结构 | 业务逻辑 |
| `Managers/` | 全局管理器 | `PetDataManager` 一类 | — |
| `Utilities/` `Utils/` | 无状态工具与扩展 | `Color+Extensions` 一类 | 业务规则 |
| `Components/` | 通用 UI 组件 | 图片选择器、预览、分享 | 业务专属组件 |
| `Rendering/` | 渲染相关（Metal、图表） | 渲染管线、绘制 | 业务判断 |
| `Resources/` | 随包资源文件 | json、种子数据 | 图片（进 xcassets） |
| `Scripts/` | 工程内脚本 | 数据种子脚本 | — |
| `Assets.xcassets/` | **所有**图片 / 颜色 / 主题素材 | imageset、colorset、ThemeSkin 命名空间 | — |
| `*.lproj/` | 本地化（9 种语言） | `Localizable.strings` | 硬编码文案 |
| `docs/` | 模块级说明 | 该模块的 README | — |

## 六、`temp/` 治理

- 定位：**临时输入与历史归档**，不是长期 source of truth。
- 已被 `.gitignore` 屏蔽（`temp/*`）。
- 整理 / 删除 / 迁移前，**先读 `docs/TEMP_GOVERNANCE_AND_KNOWLEDGE_MIGRATION.md`**，遵循「先读声明 → 再验代码 → 迁入正式目录 → 降级旧路径 → 扫残留引用 → 未授权不删」的固定顺序。
- 当前内容：`_perf/`（Instruments trace）、`acceptance/`、`ui_acceptance/`（验收截图）、`log.txt`、临时 PNG。
- 历史 `temp/_harness/`（主题复刻 harness）已在本工作区不存在，其有效内容应迁入 `docs/` 与 `tools/`。

## 七、该放哪：决策速查

| 我要加… | 放哪 |
| :-- | :-- |
| 新业务页面 | `ItemManager/Views/<模块>/XxxView.swift` |
| 跨模块通用组件 | `ItemManager/Views/Components/` 或 `Components/` |
| 新的持久化数据 | `ItemManager/Models/Xxx.swift`（+ 迁移 + ModelContainer 登记） |
| 新的业务能力 | `ItemManager/Services/XxxService.swift` |
| 全局无状态服务 | `ItemManager/Services/XxxManager.swift`（`.shared`） |
| 颜色 / 图标 / 主题素材 | `ItemManager/Assets.xcassets/`（主题走 `ThemeSkin/<namespace>/`） |
| 用户可见文案 | 对应 `.lproj/Localizable.strings` + `appLocalized` |
| 架构 / 方案文档 | `docs/`，并在 README 登记 |
| 可复用脚本 | `tools/<领域>/` |
| 一次性临时产物 | `temp/` |
| 单元测试 | `ItemManagerTests/` |
