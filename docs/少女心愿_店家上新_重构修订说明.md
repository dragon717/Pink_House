## 阶段 1：统一术语与命名规范

**改动范围**（双文档同步）：

1. **功能名**：统一为「店家上新 / 历年系列」，简称「店家上新」；不再混用「上新」「商品资料库（作为功能名）」等。
2. **运营库名**：方案 V1.0「运营工具 → 商品资料库」→ 统一为「**店家商品库**」（与计划 §32 一致）。
3. **用户端入口**：方案 V1.0 流程「首页 → 店家上新」→ 统一为「**时光馆 → 店家上新**」（计划 §2.2 为准：时光馆是底部导航第 3 个 Tab，不新增 Tab）。这是一处**逻辑矛盾修正**。
4. **实体名**：统一 Shop / Series / Product / ProductVariant / SizeChart / SaleEvent / CatalogAsset。方案 V1.0 数据模型表缺 CatalogAsset，已补。
5. **用户模型名**：统一 Wishlist（心愿）/ TailPayment（心愿尾款）/ WardrobeEntry（少女衣橱条目，primaryItem + accessories[]）+ WardrobeComponent；方案补充指向计划的字段定义。
6. **价格示例**：方案 V1.0 SaleEvent 表的「2025.11 预约 / 2026.01 现货」与计划的「2026.09 / 2026.11」矛盾 → 统一为 **2026.09 预约 ¥428 / 2026.11 现货 ¥568**（差价 ¥140，+32.7% 数学校验一致）。
7. **演示数据**：计划测试数据为店家 Alice Girl + 系列「雪国来信」，方案关键测试故事却写「UNNIQ / 雪国来信」——同一系列挂在两个店家名下，属于数据矛盾 → 统一为 **Alice Girl / 雪国来信**；UNNIQ 仅保留在计划 §9 作为「别名搜索」示例。
8. **尾款状态机 / 发布状态**：两份已一致（已付定金→待付尾款→尾款完成→加入少女衣橱；draft→submitted→reviewed→published→archived），仅补充中文对照，未改动语义。
9. **搜索范围**：计划第一版仅搜店家名/别名，方案却写「搜索店家/系列/款式」→ 统一为「第一版搜店家名称与别名；系列/款式搜索列入后续迭代」。

**影响**：不改任何业务语义，仅消除命名歧义；对开发阅读无破坏性。方案 PDF 中所有改动点均带「▲ V1.1 修订」金色标注，可逐点审计。

## 阶段 3：消除重复内容、修正逻辑矛盾（双文档）

**改动范围**：

1. **P0 范围矛盾**：计划 §42 把「系列页多选加入衣橱、小物明细、尾款多件合并写入」列为 P0，方案 §12 的 P0 列表却没有 → 以计划为准，方案 §13 P0 补齐，两文档 P0 完全一致。
2. **开发阶段矛盾**：方案 §12 的「第二阶段：我已经预约→心愿尾款；第三阶段：尾款完成→加入衣橱」与计划 Phase 1–6 是两套划分 → 以计划 Phase 1–6 为唯一口径，方案原二/三阶段并入 Phase 5，方案中注明完整划分见计划 §33。
3. **开发约束重复**：计划 §44（24 条）与方案 §15（8 条）大量重叠（不重写衣橱/心愿/尾款、预约现货不覆盖、Series/Product 不合并、淘宝只生成 Draft、不展示购买链接等）→ 合并去重为 **18 条统一约束（计划 §34）**，两文档共用同一编号；方案 §16 收录要点并指向计划。合并中补充了方案独有的约束：商品名不能作为稳定 ID、Catalog 优先归档不物理删除、淘宝导入是效率工具非前置条件。
4. **双向补漏（消重后单源化）**：
   - 方案 → 计划：明确不做清单（UGC 投稿、用户改公共资料）、解析结果三态 UI（✓/？/待补充）、运营中心展示项（今日更新/草稿/待审核/待补充）、记录预约页字段要求、MVP 验收标准、第一轮实践建议（3 店家 × 3–5 系列等）→ 分别落入计划 §2.4、§28、§26、§17、§37、§36。
   - 计划 → 方案：分类筛选完整清单、CatalogAsset、价格示例日期、时光馆入口等（见阶段 1）。
   - 单源化声明：MVP 验收标准、开发约束以计划为唯一完整版本，方案只保留摘要 + 指针，避免再次漂移。
5. **尺码表 OCR 口径**：计划 §36 原只列「尺码」未说明尺码表 OCR 边界；方案 §8.2 有明确说明 → 统一口径写入两份文档：尺码表第一版不做自动 OCR，存原图 + 运营补录结构化。

**影响**：这是语义层面的修正，影响开发范围认知（P0 对齐）与执行节奏（Phase 对齐）。若团队此前按方案 V1.0 的「三阶段」排期，需改按 Phase 1–6。
