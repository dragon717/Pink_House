# 萌宠对话重构落地计划（执行版）

> 更新时间：2026-03-25  
> 目标：将“萌宠对话”升级为情感连接主入口，并把任务进度可视化、可追踪地沉淀到文档。

## 1. 本次冻结的产品规则（先定死）

1. **聊天内闭环优先**：凡是能在萌宠对话内完成的交互，必须在对话气泡容器内完成。  
2. **单轮单气泡**：每次回复仅允许一个对话气泡容器；多信息在同一气泡并列分区展示。  
3. **引导选项内嵌**：引导选项必须在气泡容器内，不额外弹第二个气泡。  
4. **跳转守门**：除“裙装详情页”等白名单场景外，任何跳转都必须先询问用户确认。  
5. **能力清理**：移除“穿搭色/配色推荐”相关能力，仅保留裙装穿搭推荐。  
6. **状态体系升级为 4+1**：饱食、饮水、清洁、心情 + 亲密度（**桃心 icon 进度**）。  
7. **货币展示规则**：对话内可直接展示喵币（妖币）、鱼币、骨头币，不强制跳转页面。  
8. **领养与多宠规则**：首次进入对话触发领养容器；“二胎”领养消耗 60 喵币；支持对话内切换宠物管家。

## 3. 分阶段执行计划（并行推进）

### M1（基础闭环，优先级 P0）
- 单气泡渲染协议落地（文本+并列卡片+引导选项+交互容器）。
- 状态 4+1（含亲密度桃心进度）在对话中可展示。
- 货币查询卡（喵币/鱼币/骨头币）在对话中可展示。
- 下线“穿搭色/配色推荐”路径。
- 跳转守门基础版（白名单 + 二次确认）。

### M2（核心互动，优先级 P0/P1）
- 首次领养容器（奶茶/毛毛左右滑动选择 + 领养确认）。
- 二胎领养容器（60 喵币扣费 + 结果反馈）。
- 宠物切换容器（“我切换”语义触发）。
- 背包内嵌容器：查询库存、消耗道具、属性回写。
- 数钱内嵌容器：金额绑定裙装总价值。

### M3（生态联动，优先级 P1）
- 商店内嵌容器：购买/拖拽/结果回写。
- 亲密度成长引擎：行为贡献、阈值反馈、成长奖励。
- 语音指令与文本指令链路统一（同一容器协议）。

## 7. 触发规则（优先级 + 模糊触发 + 多意图分流）

### 7.1 设计目标
- 用户不需要说“精准口令”，支持自然表达、口语、省略句、混合句。
- 同一输入命中多个规则时，优先判断“主意图”；无法稳定判断时，返回**引导气泡 A/B/C**。
- 仍遵守单轮单气泡原则：分流引导也必须在同一个气泡容器内完成。

### 7.2 意图优先级（高 -> 低）

| 优先级 | 意图类型 | 示例 |
|---|---|---|
| P0 | 待确认中的事务继续（上下文强约束） | “确认”“取消”“就这个” |
| P1 | 资金/扣费/领养等交易动作 | 充值、购买、领养二胎（60喵币） |
| P2 | 宠物状态变更动作 | 喂食、喝水、清洁、切换宠物 |
| P3 | 功能面板请求 | 查看状态、查看货币、打开背包/商店、数钱 |
| P4 | 建议与信息类 | 天气+穿搭建议、库存查询 |
| P5 | 泛聊与陪伴 | 安抚、闲聊、角色互动 |

> 规则：若高优先级与低优先级同时命中，默认先执行高优先级；但若低优先级置信度明显更高（超过阈值），可提升为主意图。

### 7.3 模糊触发（非口令化）
- 采用“关键词簇 + 同义表达 + 上下文状态”联合评分，不依赖单一词命中。
- 示例同义词簇（节选）：
  - 充值：`充值/充币/充点喵币/买币/氪金/没钱了加点币`
  - 二胎：`养二胎/再养一只/领养第二只/再来一只`
  - 切换：`我切换/换一只/换奶茶/换毛毛`
  - 喂食：`吃猫粮/喂猫粮/来个罐头/给它吃点东西`

### 7.4 多意图冲突处理

1. 先做候选意图打分（score）。  
2. 若 Top1 与 Top2 分差 >= `delta_main`，直接按 Top1 执行。  
3. 若分差 < `delta_main` 或跨域冲突（如“充值 + 领养二胎”），进入**分流引导气泡**：  
   - A：最高置信候选  
   - B：第二候选  
   - C：兜底（“都不是，我换个说法”或第三候选）  

### 7.5 引导气泡模板（A/B/C）
- 标题：`我听到你可能想做这几件事`  
- 选项示例（用户句子：“我想领养二胎想充值”）：
  - A 我想充值
  - B 我想领养二胎（60喵币）
  - C 先看看我当前喵币余额
- 用户点击后，进入对应单气泡容器流程，不再二次弹多泡。

### 7.6 上下文继承规则
- 若上一轮已进入某容器（如二胎确认中），优先把本轮短句理解为该流程续操作（确认/取消/返回）。
- 若用户明确改口（“先不领养，先充值”），立即切换主意图并清理旧待确认状态。

### 7.7 监控指标（用于实验室看板）
- 多意图分流触发率
- 分流后一次点击解决率
- 分流后放弃率
- 意图误判回退率（用户点击“都不是”占比）
