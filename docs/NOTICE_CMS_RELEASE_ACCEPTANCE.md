# 公告系统上线验收总表

> 更新时间：2026-04-06  
> 用途：将 PRD、任务单、测试矩阵和 SOP 中的关键验收点收敛为一份总表，用于上线前最终核查。

## 1. 产品规则验收

- [ ] 公告中心是正式主入口
- [ ] `inbox / banner / modal` 渠道规则已定
- [ ] `severity` 与 `displayPriority` 已分离
- [ ] `draft / scheduled / published / archived` 生命周期已落实
- [ ] `Development / Production` 使用边界明确

---

## 2. 用户侧验收

- [ ] 用户能稳定进入公告中心
- [ ] 用户能查看公告详情
- [ ] 普通公告不依赖 modal 也能触达
- [ ] 关闭 banner/modal 后仍能在公告中心复查
- [ ] 确认型公告有独立确认路径

---

## 3. 渠道验收

- [ ] `info` 公告仅走 `inbox`
- [ ] `important` 公告默认 `inbox + banner`
- [ ] `critical` 公告才允许 `modal`
- [ ] modal 不在冷启动 30 秒内弹出
- [ ] modal 与 banner 不同时叠加展示

---

## 4. 数据层验收

- [ ] 主模型新字段已落地
- [ ] 用户状态模型已落地
- [ ] 旧公告迁移策略已验证
- [ ] 旧已读状态迁移策略已验证
- [ ] 过期治理已落实到系统查询

---

## 5. 管理端验收

- [ ] 管理入口独立于诊断页
- [ ] 草稿编辑、投放设置、预览、发布历史页面清晰分离
- [ ] `editor` 无发布权限
- [ ] `publisher` 可发布和下线
- [ ] `admin` 可查看回滚与审计

---

## 6. CloudKit 验收

- [ ] `Notice` Record Type 字段已齐全
- [ ] `NoticeUserState` Record Type 已存在
- [ ] 关键字段 Queryable/Sortable 已配置
- [ ] Development 已验证
- [ ] Production 已验证

---

## 7. 发布流程验收

- [ ] 正式发布仅在 `Production` 执行
- [ ] 发布前完成预览
- [ ] 发布后完成抽样验证
- [ ] 下线与归档流程可执行
- [ ] 回滚流程可执行
- [ ] 审计记录完整

---

## 8. 用户状态验收

- [ ] `unseen / read / acknowledged / dismissed` 状态流转正确
- [ ] 升级后旧公告不会大量重新变未读
- [ ] 已读用户不会被重复 modal 打扰
- [ ] 确认型公告可进入 `acknowledged`

---

## 9. 测试验收

- [ ] 生命周期测试完成
- [ ] 渠道测试完成
- [ ] 用户状态测试完成
- [ ] 权限测试完成
- [ ] CloudKit 环境测试完成
- [ ] 迁移兼容测试完成

---

## 10. 埋点验收

- [ ] 核心用户事件已定义
- [ ] 管理端事件已定义
- [ ] 同步/失败事件已定义
- [ ] 公共字段口径统一

---

## 11. 最终上线条件

以下条件全部满足，才建议进入上线：

- [ ] 产品规则冻结
- [ ] 数据层迁移完成
- [ ] 用户端与管理端主流程可用
- [ ] Production 环境已实测
- [ ] 发布/下线/回滚 SOP 已确认
- [ ] 上线前验收总表已逐项打勾

---

## 12. 冻结结论

本总表冻结以下共识：

1. 公告系统上线必须是“规则 + 数据 + 页面 + CloudKit + 测试 + SOP”整体过关。
2. 只验证弹窗能出现，不等于系统可上线。
