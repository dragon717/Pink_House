# 竞品分析报告

## 1. 竞品对象
*   **竞品 A (通用型)**: 印象笔记/Notion (用于记录手账)
*   **竞品 B (垂直型)**: 破产日记、Lolita衣橱、三坑日记
*   **竞品 C (电商型)**: 闲鱼 (二手交易记录)

## 2. 竞品功能对比

| 功能维度 | 竞品 A (笔记类) | 竞品 B (垂直类) | 竞品 C (交易类) | **少女心愿 (本项目)** |
| :--- | :--- | :--- | :--- | :--- |
| **物品录入** | 自由度高，但结构化差 | 结构化好，但字段固定死板 | 侧重交易属性，非自用管理 | **高度定制化 (支持多色/多码/小物) + 灵活标签** |
| **定金管理** | 需手动备注，无计算功能 | 支持基础定金/尾款，交互陈旧 | 不支持预售流程 | **核心功能：定金/尾款自动计算 + 智能补款提醒** |
| **UI/UX** | 商务风/极简风 | 风格较幼齿或陈旧，缺乏质感 | 商业化重，干扰信息多 | **iOS 26 液态玻璃风格，极具现代感与高级感** |
| **图片管理** | 混排 | 简单列表 | 9图模式 | **9图管理 + 主图优选 + 沉浸式浏览** |
| **提醒机制** | 手动设置提醒 | 基础推送 | 无 | **系统级日历集成 + 智能预测补款期** |

## 3. 市场痛点分析
1.  **录入繁琐**：现有 APP 往往需要填写大量非必要字段，导致用户放弃录入。
    *   *解决方案*：少女心愿 采用“渐进式录入”，仅必填名称，其他信息可后续补充；利用 AI 识别图片标签（未来规划）。
2.  **补款遗忘**：预售期长（半年甚至一年），容易错过补款导致定金没收。
    *   *解决方案*：强化的时间轴视图和多重提醒机制。
3.  **审美疲劳**：现有垂直 APP 设计风格往往过于花哨或过于简陋，缺乏符合 iOS 原生美学的高级感。
    *   *解决方案*：采用最新的 Glassmorphism 设计语言，配合流体动画。

## 4. 结论
少女心愿 的机会点在于**“极致的视觉体验”**与**“专业的预售管理流程”**的结合。不追求大而全的社区，而是先做精美的个人衣橱管理工具。
