# 详情主图遮挡与系统导航修复

更新时间：2026-10-11。

衣橱详情和时光馆商品详情原先通过负 offset 将信息卡片上提到主图区域；初始化时卡片就会盖住主图下沿。现在主图和信息区正常参与 VStack 排版，以 16pt 间距相连；名称、颜色和分页标注不再通过相互覆盖来布局。

底部导航改为系统 TabView，滚动容器由系统安全区约束。此前针对覆盖式自绘 Dock 的固定高度避让规则、修饰器与测试已删除。请勿重新给列表追加自绘 Dock 的补偿 padding；具体导航约定见 [系统底部导航约定](iOS26_导航栏统一与异形底栏方案.md)。

开屏竖向窗口使用完整原图等比缩放；宽窗口把原图标题（包含原文字和字体）、完整衣橱和进入按钮区域按相同比例左右排版，仅羽化空白边缘。按当前窗口空间选择布局，覆盖 iPad 横竖屏和折叠／展开窗口；系统启动画面使用 aspectFit 保留完整原图。

时光馆入橱先解析 canonical mediaKey、thmedia、本地上传、Bundle 或 HTTP 图片，再写入 ImageManager 的持久目录和 StoredImage 引用计数，成功后提交衣橱记录。去重命中已有 StoredImage 时会校验文件内容，丢失或损坏则重写文件后再保留引用。图片下载失败时提示重试，清理时光馆目录或媒体缓存不影响衣橱持有的图片。图片上传同步在衣橱记录提交后触发。

自动验证包含远端媒体、HTTP 错误、引用计数、删除目录及缓存后的图片可读性，以及不同窗口比例下开屏完整元素的几何和实际渲染。特定折叠／双屏真机的实际布局还需设备验收。
